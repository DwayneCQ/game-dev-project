```
       ▼                        ▼
```

### 通信协议

```yaml
Protocol:
  Transport: WebSocket (Secure: wss://)
  Serialization: MemoryPack (高性能二进制)
  Message Format: 
    - Header: MessageType (2 bytes) + Sequence (4 bytes)
    - Body: Serialized Data
    
Connection:
  Heartbeat: 30s interval
  Timeout: 60s
  Reconnect: 自动重连3次，间隔5s
  
Security:
  Encryption: TLS 1.3
  Authentication: JWT Token
  Anti-cheat: 服务器权威验证
```


## 代码规范

### 命名规范

```csharp
// 类名: PascalCase
public class PlayerController : MonoBehaviour { }

// 方法名: PascalCase
public void TakeDamage(int damage) { }

// 属性名: PascalCase
public int Health { get; private set; }

// 字段名: camelCase + _前缀
private int _currentHealth;
private string _playerName;

// 常量: UPPER_SNAKE_CASE
public const int MAX_HEALTH = 100;

// 枚举: PascalCase + 单数
public enum GameState { Loading, Playing, Paused }

// 接口: I + PascalCase
public interface IDamageable { }

// 泛型: T + 描述性名称
public class Container<TItem> where TItem : class { }
```

### 代码结构

```csharp
// 文件结构
using System;
using UnityEngine;

        #endregion
    }
}
```

### 代码质量规则

```yaml
必须遵守:
  - 单一职责原则 (SRP)
  - 依赖注入 (使用VContainer)
  - 异步使用UniTask (不用Coroutine)
  - 空检查 (?. 或 null check)
  - 异常处理 (try-catch)
  
禁止:
  - 单例模式 (用DI替代)
  - 直接FindObjectOfType
  - Update中调用GC
  - 字符串拼接 (用StringBuilder)
  - 魔法数字 (用常量)
  
推荐:
  - 使用readonly和const
  - 使用属性而非public字段
  - 使用事件而非委托
  - 使用接口解耦
```

```
│
├── develop (开发分支)
│   │
```

```
<type>(<scope>): <subject>

<body>

<footer>

示例:

- 实现账号密码登录
```

```yaml
  push:
    branches: [main, develop]
  pull_request:
```
